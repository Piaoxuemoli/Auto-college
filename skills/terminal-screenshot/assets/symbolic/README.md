# Symbolic icons (self-drawn, CC0)

按 GNOME Adwaita 图标的几何自绘（非复制原资产），可自由使用。

| 文件 | 用途 | 原版参照 |
|------|------|---------|
| `open-menu-symbolic.svg` | GNOME headerbar 汉堡菜单（16px，三条圆头线，3px 间距） | Adwaita `open-menu-symbolic` |
| `utilities-terminal-symbolic.svg` | GNOME Terminal 标签药丸里的终端字形（圆角外框 + `>_`） | Adwaita `utilities-terminal-symbolic` |

Yaru GPL-3），本仓库不引入；需要这些平台的图标时一律用本目录 CC0 自绘件、
`assets/macos-traffic-lights/`（CC0 逆向）或 CSS 等价绘制替代。
KDE Breeze 图标为 LGPL，如需可另行引入并保留许可声明。
