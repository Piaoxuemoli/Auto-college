# 成文、去重与去 AI 味

## 先有研究论证，再生成文章

写前明确读者要记住的一句话、直接建立它的一两组结果、解释机制/边界的结果、应该放方法或附录的细节。AI 可以整理、起草和改写，但不能靠流畅语言补出不存在的研究逻辑。只有想法时给真实方案和待验证稿；已有证据时直出完整论文。

常用论证序列是“现实问题 → 测量为什么可信 → 主效果 → 机制 → 边界”。按目标领域调整，不强制所有文章同一章节。严格沿用提供的模板；历史“黄金格式”若没有原文，不能宣称已遵照其精确定义。

引言建立问题重要性、最近邻未解决的具体障碍、你的可检验主张和真实贡献；Related Work 按关键差异组织，不堆人名年份。方法解释设计理由、输入输出、定义、假设和实现。Results 以问题和证据层级组织，内部实验 ID 放映射和附录。Discussion 讨论意义和解释，边界集中放在改变解释的地方。

摘要通常交代问题、方法、决定性结果和结论；数字从冻结证据取，未跑完不用“预期效果”充结果。标题准确对应主张，可以有吸引力，避免没有证明的 first、universal、fundamentally resolves、clinical-grade 等措辞。

## 段落的动作

一段只做一件事：主张 → 机制/理由 → 证据 → 必要边界。段首不要先替自己开脱。转场讲上一部分建立什么、留下什么问题、下一部分为何必要；删除“接下来/因此”后仍能解释关联，才是真衔接。

中文先给直观问题和具体机制，再术语数学。英文保持自然、准确的谓词和紧凑论证。解释达到新人理解、专家追问可核查的深度，但正式正文与教学附录分层，不能把所有教程都塞进论文。

## 去 AI 味四项检查

1. 删除测试：删掉该句是否改变事实或推理？不改变就可能是空话。
2. 异议测试：回答的是真实重要异议，还是想象中的反对者？
3. 对比测试：两件事真的对立，还是用 not X but Y 制造深度？
4. 位置测试：必要边界是否在对应证据处讲过，段末又重复一遍？

重点检查 this is not、does not imply、rather than、although、it is worth noting、promising route、potentially 等及中文对应。不能按关键词机械禁用；删除姿态，保留事实。用“覆盖四个显式约束，音乐质量由听者评价”表达真实边界，比反复写“并不能证明完整意图”更清楚。

直接证据用 shows，汇聚支持用 supports，未隔离机制用 is consistent with，未验证用 remains untested；强度跟证据走，不能全篇加 may 保守，也不能全篇改成证明。空泛高级形容词换成实际变化、对象、条件和量。

## 四种去重

**引用去重：** DOI/arXiv ID/标题作者联合匹配，合并正式版与预印本关系；cite key 更新覆盖正文。相似不自动删除，不同版本关键内容保留。

**数据去重：** 同样本重复、同长记录窗口、同会话、转载和近重复分开识别。主结果分母按真实单位去重；查重不会自动授权删除原始数据。

**论证去重：** 摘要、引言、结果、讨论有不同职责，避免重复同一段结论；相同边界集中表达，相同问题的实验合并说明，保留反证和零结果。

**措辞去重：** 减少同构句子、段末结语、无效修饰和重复“具有重要意义”。用更精确的科学内容替换，不用同义词轮换制造变化。

“去 AI”指自然写作与真实论证；不承诺绕过检测器，不通过变词掩盖抄袭，不伪造原创经历。正式查重若项目要求，使用获授权的工具并保留报告；AI 检测分数不作为学术质量真值。

## 语言与版式

遵从当前语言与 venue 模板；中文/英文一致性需要时核对，不能把两种版本不同数字留下。公式 LaTeX 定义全变量、单位和条件，图表编号与引用一致。压缩空话与不合理留白，不以缩小字体使密度看似提升。

单文件 LaTeX 使用环境内建编辑器/编译器时，保存、打开并编译；多文件稿件先检查现有项目工具链，按其构建命令。内建仅支持单文件就不要假称能编译整个工程。Overleaf 是可选目标，不是已证明的个人固定工具。交付源稿和实际编译的 PDF，视觉检查真实页，不只检查源码。

## 编辑顺序

科学主线与主张 → 方法与证据对应 → 全文数字与引用 → 冗余与自然语言 → 图表与排版。改句子后重新核对改变的事实；改分析后更新摘要、图、表、讨论和结论。不得为了“看起来更强”调数、改分母、隐藏失败或把后验结果写成主要检验。
