# Paper Writing — 调研 · 精读 · 成文 · 审稿 · 交付

**要求**：一切以真实材料与证据为基准。没有的数据、引用或结果不编造；
尚未验证的部分明确标注，交付出真实方案或待验证稿而非"看起来完整"的成稿。

## 流程线

| 阶段 | 参考 | 实质产出 |
| --- | --- | --- |
| 调研：检索、引用核对 | [literature](references/literature.md) | 最近邻矩阵、逐条核实的引用 |
| 精读：论文与代码 | [literature](references/literature.md) | 机制与代码对应、复现核对 |
| 成文：去重与去 AI 味 | [writing](references/writing.md) | 证据主线完整的真实稿件 |
| 审稿：评估与迭代 | [review](references/review.md) | 定位意见、修复映射、结论调整 |
| 交付：层级、打包、交接 | [delivery](references/delivery.md) | 成品、源文件、可续接状态 |

## 写作准绳

- 用核心主张和决定性证据组织写作，去掉重复、空话和姿态性防御，保留影响科学解释的必要边界。
- 最新反馈稿为基准，保留用户修改和未授权改动区域；完成实际成品与检查后交付。

## 交付四级

| 层级 | 可宣称状态 |
| --- | --- |
| 研究方案 | 待验证计划 |
| 阶段稿 | 尚未完成验证的草稿 |
| 完整稿 | 完整初稿或修订稿 |
| 提交候选 | 可供作者最终确认的提交候选 |

不存在承诺录用的层级；各级内容与边界详见 [delivery](references/delivery.md)。

## 论文图极简原则

图呈现科学关系而非装饰；每张图的 caption 对应正文的具体主张；
数据图由脚本从原始记录生成，不手工摆数。

## 独立性

本 skill 自包含：输入材料可来自任何来源（用户提供的文件、公开文献、已有项目目录），
不依赖任何其他 skill 或外部脚本。
