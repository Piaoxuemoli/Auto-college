# 运行与阶段规则

## 第一轮理解

从材料取得中心问题、领域读者、已有理论方法、数据代码、结果、最新稿件、会议期刊模板、语言、算力/调用权限、时间费用和公开范围。作者信息来自当前项目。先读文件，常规工具和排版自行决定，不把清单变成十几个必答问题。关键缺口集中询问，继续不依赖答案的工作。

无预算先用已授权本地资源与小规模验证，不新购云 GPU 或扩大付费 API。已有授权覆盖的执行不重复确认。

## 阶段与通过条件

| 阶段 | 动作 | 下一阶段依据 |
| --- | --- | --- |
| S0 接手 | 读 context、roadmap、源文件日志 | 已完成、缺口、版本与下一问题明确 |
| S1 定题 | 现象、可检验问题、最近邻、差异价值 | 主张可证伪，测量与关键对照可实现 |
| S2 精读 | 原文、补充、官方代码、数据协议 | 机制、输入输出、形状、复现缺口能解释 |
| S3 协议 | 指标、单位、划分、对照、预算、失败、选择规则 | 决定性实验区分主张和替代解释 |
| S4 试验 | toy、小试、实现检查、资源估算 | 代码工作，协议有识别力，结果完整 |
| S5 验证 | 主实验、消融、机制、边界、鲁棒性、不确定性 | 主张有原始证据，失败有记录，无测试集调参 |
| S6 成文 | 证据大纲、方法、结果、引言、摘要、图引 | 完整论证和每个数字的来源 |
| S7 审阅 | 科学、引用、数字、编译、视觉检查 | 主要问题关闭，结论范围准确 |
| S8 交付 | 成品、源码、复现、状态、交接 | 可打开、能运行、未完成项明确 |

这不是僵硬瀑布：精读可改变定题，试验可改协议，负结果可改主张。已完成部分不重复；局部修改重检受影响部分。理论论文不强塞训练实验，综述不假装新算法，审稿保持只读。

## 自主推进循环

找核心结论的最大不确定性 → 选择能区分解释的最小动作 → 实际检索/推导/执行 → 保存原始输出 → 更新主张 → 有信号再扩大，没信号重审 → 回到主线交付。

502、路由不可用、超时和没有科学效应分别记录。失败按预先协议处理，不能静默移出分母，不能把网络故障写成算法失败。服务故障有限重试；实验单元是否重试遵从科学协议。

## 收敛与停止

本轮范围和核心检查通过就交付，支线留待未来。资源不足交付诚实方案、阶段稿或否定/边界结果。用户暂停立即停止。无新指令，不因额度恢复、重启、时间或别的任务消息恢复。

同一主要缺口多轮未解决，重审问题与证据价值，再选择补实验、调整结论、换论文类型或报告资源缺口。不能以刷到 accept 为停止条件；录用预测只是有理由的主观判断。

## 状态与衔接

三个入口：`PROJECT_CONTEXT.md` 记录事实决定；`ROADMAP.md` 记录问题依赖优先级；引用库由 `paper/references.bib` 和 `ledger/references.jsonl` 组成。`RUN_STATE.json` 可记录阶段、稿件、检查和授权。

区分观察、推断、决定、待验证；记录最近真实检查的文件命令。关键实验或修订完成就保存，不让记录占据主任务。新会话先核实文件日志和当前用户授权；状态文件不是自动启动许可。上下文压缩可继续当前任务，已经结束的任务等待新指令。

## 协作与算力

仅在用户或环境明确授权时委派。独立审稿提供冻结稿、数据代码协议，不提供作者辩护。单模型另一次角色审阅应标为自审，不能冒称上下文隔离的独立评审。

授权服务器先查空闲 GPU、显存、他人任务与依赖，小试估速后部署。共享机器不挤占他人卡，不终止未知任务。他人环境的硬件配置与登录别名不随项目迁移，既不是可用配置也不是授权。
