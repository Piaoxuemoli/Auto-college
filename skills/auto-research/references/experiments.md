# 实验、复现与评估

## 将想法变为能区分解释的研究

先明确主张、观测单位、输入输出、主要指标、比较对象、适用范围与反例。给每个核心假设一个可证伪预测，写清什么结果支持、什么结果反对、什么结果仍不确定。把“算法很强”“足够泛化”“A 会水准”转为具体可以测的关系。

最重要的实验通常是：主要效果是否存在、测量/评估器是否可信、是不是额外算力或其他混杂产生、机制是否成立、何时失效。实验按回答的问题分配，不以数量和模块数量证明深度。

协议在主要测试前确定：样本/实验单位、排除规则、数据划分、预处理拟合范围、基线信息权限、训练/调用预算、选参/选 checkpoint、统计估计量、不确定性与失败处理。探索后新增分析允许，但如实标记；不要把后验分析改称预注册主检验。

## 公平与泄漏

train/validation/test 独立，按来源分组再切窗，避免同一长记录、受试者、会话、发射源或多轮对话跨 split。归一化、特征选择、阈值、校准、early stopping 都只能用允许的数据。最终测试集不用于挑方法、种子或最漂亮的 checkpoint。

基线共享 split 和主要预算，忠实复现官方协议；另行标记 oracle、额外标签、预训练、验证权限和调用次数。训练与评估变换一致，例如移除某区域的基线不能训练时移除、测试时恢复。需要重启模型的算法不能以继续训练替代。

oracle 不只当强基线，还说明信息上限。matched-budget、matched-timing、always-on、固定时间、无信号/无捷径、区域特异性控制按主张选择；不要机械全部加入。

## 从 toy 到真实实验

toy 验证推导、实现和边界；小 demo 验证测量、失败类型和资源；真实数据验证外部有效性。每级写明支持到哪层，toy 不能直接证明真实卫星/生理场景。

先跑能区分解释的小试，检查样本和指标，不为“有数字”盲目扩大。通过后决定重复数和样本规模；依据实验单位、效应精度、可用预算选择，不把所有项目固定成 5 seeds。

每次记录数据/代码版本、完整参数、种子、split 清单、设备软件、时间预算、状态、原始结果、异常和重跑命令。原始输出不覆盖；生成表与图由分析脚本从记录导出，避免手抄数字。

## 统计核对

独立单位通常是受试者、站点、采集会话、任务或对话，seed 往往是重复测量，不能都当独立样本。配对、层级或 cluster bootstrap 按设计选择；交互和多重比较按主要问题定义。报告效应量与区间，不只报告 p 值；单/双侧、标准差/标准误、百分点/相对百分比区分清楚。

从混淆矩阵计算 Cohen's kappa，不能仅用准确率和假设均匀边际反推。宏平均、微平均、worst-group、样本加权和论文中调整平均要注明。均值、std、分母、缺失、完成数、负结果逐项对回日志。

统计脚本通过只证明计算实现通过，不能证明实验单位选对、因果可识别或研究成立。缺失结果用缺失状态，不能补零、补“合理值”或调整 seed 让方法获胜。

## 领域中的重点

| 领域 | 必须查的识别问题 |
| --- | --- |
| EEG/多模态生理 | LOSO/跨 session/随机划分区别；目标域无标签适配与 calibration-free 区分；信号尺度、滤波、协方差秩、受试者单位；各模态同步与缺失 |
| 神经科学分解 | cue/token 时刻对齐与 latency；试次平均和神经元平均不同；脑区信息保持；价值/显著性设计矩阵与正交条件；统计单位与因果措辞 |
| RF/雷达 | IQ、PSD、时频、信道对象的能力边界；采样率带宽、SNR、单位和校准；模拟与实测分别报告；硬件链路与算法误差区分 |
| 卫星/电磁地图 | 地面/无人机/LEO/MEO 证据分别标记；轨道、载荷、频段、几何、天线、链路预算；动态观测与标签来源；仿真不能冒充中轨实测 |
| LLM/API/agent | 实际模型路由、版本、system prompt、推理档位、token/轮数预算；任务完成与错误传播定义；多轮任务，fresh 闭环；未知类别和校准数据来源 |
| 音乐/程序语义 | 正确性 oracle 与音乐质量不同；语义、事件、可听结果和人评的关系；oracle 自身差分/变形/专家核验；原失败不换 population 掩盖 |
| 数据库/benchmark | 标签依据、覆盖率和置信度分开；独立标注者一致性；采样偏差、重复、标准版本；检索/下游任务/人审验证；私有数据复现边界 |

## 技术栈和资源

常见栈涉及 Python、Matplotlib、PyTorch/CUDA、MATLAB、LaTeX、PowerPoint、Zotero、Git/GitHub、本地与授权 GPU 服务器；不要求每项任务都用所有工具。NumPy/SciPy、pandas、Jupyter 等可按实现选用，不冒称每项都是固定偏好。

优先复用项目环境，读现有依赖与命令，避免重复安装。GPU 先查占用和显存，用小试估速；共享服务器尊重用户释放卡的要求。付费 API/云实例在当前授权预算内使用，真实型号与路由必须核实。核心实验测试有意义的行为与失败路径，不为低影响排版改动制造测试。

## 结果不符合预期时

依次判断实现/测量是否可信、对照是否公平、假设是否成立、研究问题是否有价值。允许形成反直觉、无效、条件性结论。只有新实验能真正区别解释才继续；不要以扩大模型、增加模块和重写标题来掩盖识别失败。
