# Editable Slides — 可编辑科研图验收与参考风格适用范围

## 可编辑科研图验收

先定图、标题、图注和页脚的可用边界，再按完整包围盒缩放节点、字体、线宽和箭头。
检查椭圆、连接点、交叉、密度和阅读路径；没有越界不代表合格。科学、视觉、编辑能力、
指定文件行为分别查。

目标图中融入节点，不能用原图缩小加旁边大块解释代替。

## 指定文件更新与备份

用户要求在原 PPT 新增 slide，就更新指定文件；构建备份放工作目录。所有新增/修改
组件 `noGrp=0` 或省略，交付前查无意的 `noGrp="1"`/`true`。

## 参考风格适用范围

| 场景 | 风格 |
| --- | --- |
| 组会 | 常见白底、深蓝标题、中文讲解和英文原图，较高密度且有层次 |
| 论文图 | 更克制 |
| 前端 | 可有动画与玻璃效果 |

三种场景不能混用。最新参考稿优先，不把某一参考稿的配色固定到所有项目。
