# Figure Routing — 图职责、路线选择与参照/生图规则

## 先选图的职责

每张图回答一个明确问题：方法如何工作、主要效果是什么、机制为何成立、条件在哪里、
系统对象如何连接。先冻结数据/科学内容，再决定图形。图号和 caption 与主张 ledger
对应，不能为美观改变科学关系。

## 路由表

| 图类型 | 默认路线 | 验证 |
| --- | --- | --- |
| 实验曲线、统计、频谱、热图 | 原始数据 + 标准绘图库 | 数值、聚合、单位、区间、分母、轴与日志一致 |
| 论文原图引用 | 原文 PDF 与图注；记录来源 | 图号页码、版本、解释和使用条件 |
| 给了高质量参照的可编辑图 | 原生对象复刻或复用 | 节点、箭头、比例、样式与编辑能力 |
| 无参照的科研架构/机制图 | 内容规格 → 查实际论文参照 → 适配；仍缺构图才考虑合规生图 | 拓扑和语义准确，最终格式满足要求 |
| 原图增加节点/关系 | 沿用原样式，必要时整体重排 | 新旧字体、比例、密度、颜色语义一致 |
| 3D 几何、坐标、波束 | 代码/仿真生成演示 | 角度、坐标、参数、简化假设、入口实际可用 |
| 网页交互、SVG/Canvas 创意图 | 前端或代码直接实现 | 交互、数据、可维护性与实际呈现 |

"扒图"在可编辑 PPT 场景中通常指复刻，不能仅截图贴进去。确认任务语义后执行，
不给所有任务强塞 PPT。

## 参照复刻优先

有成熟参照直接复刻，不重设计。无参照先查当前资料库和外部论文，实际打开图及图注，
比较内容、拓扑、分区、比例和密度；经典/高引不是结构匹配的替代。

## 生图门禁（参数化）

仅在可信配置确认实际路由为**项目指定模型**时才调用生图。准确型号与可调用性以
目标环境的可信元信息/固定配置为准，本文不替任何工具保证路由。以下均不证明实际路由：

- 提示词里写了型号；
- 官网存在该模型；
- 工具名字或输出质量看起来对。

路由未知或未配置 → 不生成、不降级，继续参照复刻或数据绘图。

模型与接入走用户级配置文件 `~/.auto-college/image-gen.json`
（字段：`provider` / `base_url` / `model` / `api_key`），无配置文件或字段不全
即不生成。

生成图只提供构图/插画参考，不制造实验数据、曲线、统计显著性或论文证据。
原生可编辑交付需要把必要节点、文字和连线实现为实际对象；单张扁平 SVG 或位图
不能冒充逐项可编辑。

## 科研生图提示规格（有合规路由才使用）

写明用途与最终媒介，逐一标记输入图为"结构参照/风格参照/需保留原图"；列出必要
节点和标签、包含关系、箭头起终点及含义、阅读顺序；说明可变区域、待解决密度/比例
问题、目标尺寸；限定不添加未经证实的关系、数值和装饰术语。不要只写"顶刊、高级、
科技风"。

## 生成后核对

对照内容规格查漏项、重复、反箭头、错字和错误包含关系，再原生实现。视觉方向有问题
回到参照或构图，不反复微调错误方向的代码框图。
