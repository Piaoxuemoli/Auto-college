# Proposal: report-image-embedding

- 议题：T3 实验报告图片嵌入（见 `docs/roadmap.md`）
- 状态：draft（roadmap 原状态 open；本提案给出候选默认值，待讨论确认）

## 为什么

截图存 `outputs/<exp>/screenshots/` 并以 MD 引用，DOCX 导出靠官方 docx skill
插图，但图注、编号、尺寸约束与失败回退均未定义：报告间风格漂移，
导出后图片行为不可预期。

## 做什么（建议默认值，待确认）

- 图注：统一编号式"图 1-1 标题"（章-序），英文模板同构 `Figure 1-1`；
- 引用：MD 内相对路径引用 `screenshots/`，导出阶段统一改写为可解析路径；
- 尺寸：入文图片统一最大宽度约束（建议 600px 逻辑宽），超限自动缩放；
- 压缩：PNG 超约 2MB 自动降采样，原图保留于 `raw_outputs/`；
- 中文字注：跟随文档主字体，不单独要求；
- 失败回退：图片丢失/导出失败时保留图注 + 路径占位说明，不阻断交付。

## 取舍

- 编号式 vs 无编号：选编号式——实验报告需要交叉引用；
- 自动压缩 vs 原图直入：压缩换交付体积，原图保留保证可追溯；
- roadmap 的三个待讨论点（图注格式/压缩/中文字体）本提案均给出默认值，
  讨论可推翻；推翻时只改本文件与 tasks 验收值，不动 specs 基线。
